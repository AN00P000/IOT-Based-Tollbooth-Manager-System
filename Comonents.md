Hardware :
1. Arduino board : Arduino uno
2. RFID Reader : for vehicle identification 
3. Servo motor or Stepper motor : for opening or closing of gates
4. Ultrasonic sensor : for vehicle detection 
5. LED Display : for showing Toll amount
6. Power supply : battery

Software :
1.Arduino IDE: for programming the Arduino
2. Libraries : for RFID and other sensors
3. Code: for controlling the hardware components and managing the toll booth operation
 
Tools :
1. Soldering iron and solder : for connecting components
2.Breadboard: for assembling the circuit
3.Jumper wires : for connecting components
4.Computer with USB port : for programming the Arduino and other components
